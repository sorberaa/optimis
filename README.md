# 🔥 Optimus Gang — Игровой Telegram Бот со стикерами и магазином

Полнофункциональный игровой бот для групповых чатов и личных сообщений в Telegram, разработанный специально для сообщества и магазина **Optimus Gang**.

Игроки соревнуются в азартных играх с официальными анимированными эмодзи-костями Telegram (⚽, 🏀, 🎯, 🎳, 🎲, 🎰), устраивают PvP-дуэли на ставки, выбивают джекпоты прямо в чате и обменивают выигрыш на реальные скидочные купоны в магазине **Optimus Gang**!

---

## 🎮 Возможности и механики

### 1. 📋 Проведение игр по готовому списку от шефа (`/list_game`)
- Админ отправляет команду `/list_game` вместе со списком участников (или отвечает реплаем на сообщение со списком):
  ```
  /list_game
  1. @ivan
  2. @sergey
  3. @alex
  4. @dmitry
  ```
- Бот сам очищает нумерацию и тире, загружает список и предлагает выбрать дисциплину и приз.
- **Два режима проведения:**
  - ⏱ **Живой ход (с правилом 2 минут):** Бот вызывает каждого игрока по очереди. На ход даётся ровно **2 минуты** (120 секунд). Если человек не ответил — **автоматическая дисквалификация (DQ ❌)**!
  - ⚡ **Быстрый авто-бросок:** Бот сам разыгрывает броски за каждого участника за считанные секунды.

### 2. 🎰 Интерактивные рулетки с самозаписью участников (`/roulette`)
- Админ запускает рулетку в чате с выбором мест (например, 10 мест).
- Бот отправляет сообщение в чат с живым списком и кнопкой `[🎟 Записаться]`.
- Участники сами занимают слоты. При заполнении игра стартует автоматически.

### 3. ⚔️ PvP Дуэли 1 на 1 (`/duel`)
- Игрок выбирает игру и ставку (25, 50, 100, 250, 500 🪙 или All-in).
- Бот отправляет интерактивный вызов в чат с кнопкой **«Принять вызов»**.
- Любой участник чата может принять бой (ставка списывается у обоих).
- Бот по очереди бросает анимированные эмодзи для каждого дуэлянта с задержкой на анимацию.
- Сравниваются результаты бросков: победитель забирает весь банк! При ничьей ставки возвращаются.

### 2. 🎲 Одиночная игра против бота
- Быстрый режим игры 1 на 1 против искусственного интеллекта Optimus Gang.
- Выигрыш удваивает ставку.

### 3. 🎯 Живая реакция на стикеры в чате (Пассивный режим)
Участники чата могут просто отправлять официальные эмодзи-кости Telegram:
- ⚽ **Футбол:** Гол (+5 🪙), Гол в «девятку» (+15 🪙).
- 🏀 **Баскетбол:** Попадание (+5 🪙), Чистый трехочковый (+15 🪙).
- 🎯 **Дартс:** Точный выстрел (+5 🪙), Яблочко (50 очков) (+30 🪙).
- 🎳 **Боулинг:** Страйк (+30 🪙).
- 🎲 **Кости:** Шестёрка (+10 🪙).
- 🎰 **Слоты:** Три в ряд (+25 🪙), Джекпот 777 (+100 🪙).
*(Встроен умный анти-спам кулдаун для защиты от накрутки).*

### 4. 🛍 Магазин скидок Optimus Gang (`/shop`)
- Игроки обменивают монеты на реальные скидки в магазине:
  - Скидочный промокод 5% (300 🪙)
  - Скидочный промокод 10% (600 🪙)
  - Скидочный промокод 15% (1000 🪙)
  - VIP-статус в чате (1500 🪙)
  - Кастомный титул (500 🪙)
- Личный инвентарь купленных промокодов доступен по кнопке **«🎒 Мои покупки»**.

### 5. 🎁 Экономика и бонусы
- **Приветственный бонус:** 200 🪙 каждому новому игроку.
- **Ежедневный бонус (`/bonus`):** +100 🪙 раз в 24 часа.
- **Зал славы (`/top`):** Таблица лидеров по балансу монет и по количеству побед.
- **Профиль игрока (`/profile`):** Ранги (от «Новичка» до «Легенды Optimus Gang»), винрейт, количество побед и поражений.

### 6. 👑 Админ-панель (`/admin`)
- `/give [id/ответ] [сумма]` — выдать монеты.
- `/take [id/ответ] [сумма]` — списать монеты.
- `/add_item Название | Описание | Цена | Промокод` — добавить новый купон в магазин.
- `/broadcast [текст]` — рассылка по всем игрокам.
- `/stats_admin` — статистика пользователей, балансов и покупок.

## 📁 Структура проекта

```
optimus_gang_bot/
├── bot.py                # Главный файл запуска бота
├── config.py             # Настройки и переменные окружения

├── run.bat               # Скрипт быстрого запуска в 1 клик для Windows
├── .env                  # Конфигурация (токен и параметры)
├── .env.example          # Шаблон конфигурации
├── handlers/             # Обработчики сообщений и кнопок
│   ├── __init__.py       # Регистрация всех роутеров
│   ├── common.py         # /start, /help, главное меню
│   ├── games.py          # Дуэли, игра с ботом, обработка стикеров в чате
│   ├── profile.py        # Профиль, топ игроков, ежедневный бонус
│   ├── shop.py           # Магазин товаров и купонов
│   └── admin.py          # Админ-команды и управление
└── keyboards/            # Клавиатуры бота
    ├── __init__.py
    └── inline.py         # Инлайн-кнопки меню, игр, магазина и ставок
```

## 🚀 Быстрый запуск на Windows

1. Дважды кликните по файлу **`run.bat`** в папке проекта.
2. Скрипт сам:
   - Найдёт Python на компьютере;
   - Создаст виртуальное окружение `.venv`;
   - Установит библиотеки из `requirements.txt`;
   - Запустит бота!

Либо вручную через терминал:
```bash
pip install -r requirements.txt
python bot.py
```

## ⚙️ Настройка прав бота в группе Telegram

1. Добавьте бота в чат сообщества **Optimus Gang**.
2. Сделайте его администратором группы со следующими правами:
   - ✅ **Отправка сообщений**
   - ✅ **Отправка медиа / стикеров / костей**
   - ✅ **Управление сообщениями** (для редактирования карточек дуэлей)
3. Отключите Group Privacy в [@BotFather](https://t.me/BotFather):
   - Отправьте `/setprivacy` -> выберите вашего бота -> нажмите **Disable**.
   *(Это нужно, чтобы бот видел отправленные участниками кости-эмодзи ⚽🏀🎯 прямо в чате).*
