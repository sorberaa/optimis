1. КАК СДЕЛАТЬ ВАС ГЛАВНЫМ АДМИНИСТРАТОРОМ (ВЛАДЕЛЬЦЕМ):
-------------------------------------------------------------------
Вариант А (в файле .env):
1. Узнайте свой Telegram ID: напишите боту @userinfobot (он пришлет цифры, например: 123456789).
2. Откройте файл .env блокнотом и вставьте ваш ID в строке:
   ADMIN_IDS=123456789
3. Сохраните файл. Теперь у вас высший статус Главного Админа с доступом ко всем функциям!

Вариант Б (прямо через чат):
Любой действующий админ может ответить на ваше сообщение в чате командой:
/add_admin
И вы мгновенно станете администратором бота.


2. КАК ЗАПУСТИТЬ БОТА:
-------------------------------------------------------------------
- На Windows: просто дважды кликните по файлу run.bat.
  (Он сам проверит зависимости и запустит бота).
- На сервере (Linux / VPS):
  pip install -r requirements.txt
  python bot.py


3. НАСТРОЙКА БОТА В ВАШЕМ ЧАТЕ:
-------------------------------------------------------------------
1. Добавьте бота в чат Optimus Gang и сделайте его администратором (права на отправку сообщений и стикеров).
2. В боте @BotFather отправьте /setprivacy -> выберите вашего бота -> нажмите Disable (чтобы бот видел стикеры в чате).


4. ОСНОВНЫЕ КОМАНДЫ ДЛЯ ШЕФА:
-------------------------------------------------------------------
• /game [мест] [приз] — быстрый запуск рулетки в чате (например: /game 10 Роль в чате).
  Люди заходят сами, нажимая кнопку [Записаться].
• /list_game — запустить игру по готовому списку участников (отправьте список текстом или ответьте командой на сообщение со списком).
• /admin — панель управления (назначение админов, статистика, начисление очков).
• /duel [ставка] — дуэль 1 на 1 со стикерами.
• /shop — магазин титулов и значков к нику.

-------------------------------------------------------------------
